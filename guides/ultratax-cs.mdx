UltraTax does this through **Client Listing Reports**. Pick a report, pick who's on it, export to Excel.

## Steps

<Steps>
  <Step title="Utilities, then Client Listing Reports">
    Both off the main menu.
  </Step>
  <Step title="Pick a report">
    **General Client Information** is the one you want for bringing a book over. **Client Contact** if you also want phone numbers and email addresses.

    There are ten in total: General Client Information, General Return Information, Client Contact, Client Communications, Status Summary, Client Totals, Client Family, Client Status History, User Activity, Client ELF Summary.
  </Step>
  <Step title="Pick a sort order">
    From the **Sort** field next to the report. Doesn't matter which — Pernee reads it either way.
  </Step>
  <Step title="Choose who's on it">
    Narrow the list with the **Focus** group, then move clients from **Clients available to print** across to **Clients to print**.
  </Step>
  <Step title="Export">
    Opens a **Save As** dialog.
  </Step>
  <Step title="Excel, and tick the headings box">
    File type **Excel 97-2003 Workbook**. DIF works too if you'd rather.

    Tick **Include column headings**. Do this one. Without headers Pernee has to work out what each column is from the contents, and you'll spend the time you saved fixing flagged rows.
  </Step>
  <Step title="Name it and save">
    That's it.
  </Step>
</Steps>

<Note>
  An `.XLS` file is fine. No need to convert it to anything first.
</Note>

## Then bring it in

Drop the file into the card in Getting started, or open **Clients** and choose **Import clients**.

Pernee reads the file, proposes a name, entity type, return form and tax year for each row, and shows you the lot on a review screen. Nothing saves to your book until you hit **Import**.

<Tip>
  Keep the UltraTax client ID in the export. Pernee holds onto it, so a later import updates the client you already have instead of creating a second one.
</Tip>

## If you need a narrower list

**Data Mining** builds a more specific one — clients on extension, a single return type — and exports the same way. The spreadsheet imports identically.

Running something else too? See [Getting your client list into Pernee](/guides/overview).
