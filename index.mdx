Pernee remembers the review comments your team made on a client's return last
year, and brings them back to the reviewer working on this year's — on the same
line, with the original comment cited.

## How a review works

<Steps>
  <Step title="Open the return you're reviewing">
    Pernee lines up this year's return against the review history for the same
    client.
  </Step>
  <Step title="Ask for a draft">
    Pernee proposes the checkpoints worth looking at, and shows you the
    prior-year review comment each one came from.
  </Step>
  <Step title="You decide">
    Every suggestion is a draft. You accept, edit or discard it.
  </Step>
</Steps>

<Note>
  Pernee never files anything and never writes back into your tax software.
  Everything it produces is a draft for a person to approve.
</Note>
